# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.8

Проект содержит законченную первую главу, единый серверный прогресс и самостоятельную оболочку PWA:

- один корневой интерфейс вместо наложенных друг на друга локальной и серверной игр;
- отдельный экран входа и регистрации;
- гостевой пролог включается явно как демонстрация и не смешивается с общей экономикой;
- семь серверных разделов: путь, герой, мастерская, рынок, гильдия, чаты и аккаунт;
- адаптивная навигация для компьютера и телефона;
- серверный герой с одним из шести ремёсел;
- 16 авторских сцен и три сюжетных расследования с моральными развязками;
- профессии, предметы, доказательства, монеты, силы и решения проверяются сервером;
- сюжет, вольные контракты, гильдия, мастерская, рынок и инвентарь используют одного героя и одну экономику;
- пошаговый бой с намерениями врага, защитой, подготовкой, ремесленным приёмом и отступлением;
- окончательная смерть, поколения наследников, слава рода и семейная реликвия;
- серверные травмы влияют на расход сил и лечатся только в безопасном месте;
- предметы имеют тип, качество, прочность, поломку, экипировку и число ремонтов;
- атаки и ремесленные приёмы изнашивают экипированный инструмент;
- подтверждённые вольные контракты дают разные серверные материалы;
- ветка гильдии «Промысел» увеличивает основную добычу материалов;
- мастерская содержит рецепты, точные требования, запасы, временные эффекты и журнал работ;
- кузнец перековывает инструменты и получает больше ремкомплектов;
- травник создаёт лечебные припарки;
- охотник и возчик укрепляют максимальную прочность инструмента;
- писарь создаёт обереги следующего похода;
- странник собирает универсальные походные наборы;
- торговая площадка позволяет выставлять материалы и расходники по цене за единицу;
- при создании объявления товар сразу списывается из инвентаря в серверный резерв;
- частичная покупка уменьшает зарезервированный остаток, полная закрывает объявление;
- отмена возвращает только непроданный остаток;
- покупка одной транзакцией списывает монеты, передаёт товар и зачисляет выручку продавцу;
- рынок удерживает 5% комиссии с крупных сделок как вывод монет из экономики;
- самопокупка, продажа инструментов, реликвий и сюжетных предметов запрещены;
- последние сделки хранят покупателя, продавца, количество, цену, комиссию и итоговую выручку;
- создание объявления, покупка, отмена, производство, ремонт и награды защищены одноразовыми `requestId`;
- повторный запрос не может повторно списать товар или монеты;
- первая завершённая глава выдаёт добротный дорожный тесак;
- первый завершённый сюжетный контракт выдаёт уникальную Печать основателя;
- создание гильдии атомарно списывает 12 серверных монет и Печать основателя;
- общие гильдии до 20 игроков, приглашения, пользовательские роли, дерево, задания, казна и журнал операций;
- WebSocket-чаты `#Общий`, `#Торговля`, `#Гильдия` с переподключением и закрытым гильдейским каналом;
- офлайн-очереди безопасно повторяют неподтверждённые сюжетные и боевые действия после восстановления связи;
- производство и рынок намеренно не работают через офлайн-очередь: сервер должен подтвердить актуальные остатки;
- введён реестр нумерованных SQLite-миграций с транзакционным откатом;
- Service Worker не кэширует приватные API-ответы;
- автоматические тесты покрывают аккаунты, сюжет, бой, наследование, миграции, травмы, предметы, гильдии, добычу, производство и рынок.

## Текущее техническое ограничение

На рынке продаются только складируемые материалы и расходники. Инструменты с индивидуальной прочностью и качеством пока нельзя выставлять, потому что для них нужна отдельная модель уникальных экземпляров. Также ещё не реализованы прямые заказы конкретному ремесленнику, передача между друзьями, поиск и фильтрация по типу товара, срок жизни объявления и региональные цены.

## Запуск

Требуется Node.js 22.13 или новее. Node.js 22 LTS поддерживается.

```bash
npm install
npm run dev
```

PWA откроется на порту `5173`, API и сервер чатов работают на `3001`.

Команда `npm run dev` запускает сервер и Vite напрямую через исполняемый файл Node.js, поэтому одинаково работает в Windows, Linux и GitHub Codespaces.

Если нужно запустить процессы раздельно:

```bash
npm run dev:server
npm run dev:web
```

Эти команды выполняются в двух отдельных терминалах.

Данные аккаунтов, героев, сюжета, травм, предметов, материалов, производства, рынка и гильдий сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. Порт задаётся переменной `PORT`, путь к базе можно переопределить через `DATABASE_PATH`. По умолчанию используется порт `3000`.

## Команды

```bash
npm run dev          # клиент и основной сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, проверка типов и production-сборка
npm start            # запуск production-сервера
```

## Принципы проекта

1. Ремесло открывает способы решения проблем и полноценные производственные цепочки, а не просто даёт проценты к характеристикам.
2. Мир не делится на очевидное добро и зло, но последствия решений должны быть понятными задним числом.
3. Рогалик наказывает за риск, но метапрогресс сохраняет знания и память, не отменяя цену смерти.
4. Онлайн дополняет личный путь через чаты, гильдии, торговлю и общие события.
5. Сервер является источником истины для сюжета, героя, экономики, материалов, производства, рынка и наград.
6. Каждая система проходит цикл: реализация, проверка, исправление и повторная проверка.
