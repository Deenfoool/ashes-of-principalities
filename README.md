# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.4

Проект содержит законченную первую игровую главу, общий онлайн-слой и серверного героя аккаунта:

- создание героя с именем и одним из шести ремёсел;
- пролог и три полноценных сюжетных контракта с расследованиями и моральными развязками;
- уникальные ремесленные решения и боевые действия;
- детерминированный пошаговый бой с намерениями противника, защитой, подготовкой и отступлением;
- уровни, опыт, здоровье, силы, чутьё, репутация, монеты и инвентарь;
- окончательная смерть, поколения наследников, слава рода и семейная реликвия;
- необязательные аккаунты: сюжетная глава остаётся доступна без регистрации;
- отдельный серверный герой, чьи характеристики, монеты, предметы и походы хранятся в SQLite;
- три серверных контракта с наградами, трофеями и серверно рассчитанным боем;
- одноразовые идентификаторы действий: повтор запроса не удваивает награду, взнос или начало похода;
- очередь действий PWA после разрыва соединения с безопасным повтором того же запроса;
- общие гильдии с лимитом 20 участников и вступлением только по приглашению;
- пользовательские роли, серверная проверка прав и защищённая иерархия;
- общая казна и полный журнал операций;
- взнос в казну сначала списывает реальные монеты серверного героя;
- гильдейские контракты и победы засчитываются только после подтверждения сервером;
- еженедельные задания, уровни гильдии и пять веток дерева;
- WebSocket-чаты `#Общий`, `#Торговля`, `#Гильдия` с переподключением и закрытым гильдейским каналом;
- адаптивная устанавливаемая PWA для телефона и компьютера;
- Service Worker не кэширует приватные API-ответы;
- автоматические тесты аккаунтов, API, персонажей, боёв, наследования, идемпотентности, гильдий и чатов;
- единый запуск клиента и сервера в GitHub Codespaces.

## Текущее техническое ограничение

Авторская сюжетная глава и серверные походы пока существуют как два связанных, но отдельных слоя. Сервер уже является источником истины для аккаунтного героя, его боевых наград, инвентаря, личных монет и гильдий. Следующий этап — перенести авторскую главу на тот же серверный формат сцен и постепенно убрать старое локальное состояние персонажа.

## Запуск в Codespaces

1. Открой репозиторий в GitHub Codespaces.
2. Дождись выполнения `npm install`.
3. Запусти:

```bash
npm run dev
```

Игра откроется на порту `5173`, API и сервер чатов работают на `3001`.

Данные аккаунтов, героев и гильдий сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. Порт задаётся переменной `PORT`, путь к базе можно переопределить через `DATABASE_PATH`. По умолчанию используется порт `3000`.

Для серверной SQLite-модели требуется Node.js 24.15 или новее.

## Команды

```bash
npm run dev          # клиент и сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, проверка типов и production-сборка
npm start            # запуск production-сервера
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не просто даёт проценты к характеристикам.
2. Мир не делится на очевидное добро и зло, но последствия решений должны быть понятными задним числом.
3. Рогалик наказывает за риск, но метапрогресс сохраняет знания и память, не отменяя цену смерти.
4. Онлайн дополняет одиночный путь через чаты, гильдии, торговлю и общие события.
5. Сервер является источником истины для общей экономики и наград.
6. Каждая система проходит цикл: реализация, проверка, исправление и повторная проверка.
