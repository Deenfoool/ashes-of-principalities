# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.11

Проект содержит законченную первую главу, две игровые области и единый серверный прогресс:

- один корневой PWA-интерфейс для компьютера и телефона;
- регистрация, HttpOnly-сессии, SQLite-база и серверный герой одного из шести ремёсел;
- 16 авторских сцен и три расследования первой главы с моральными развязками;
- окончательная смерть, поколения наследников, слава рода и наследуемые торговые активы;
- две области свободных походов: **Пепельный тракт** и **Соляные топи**;
- Пепельный тракт открывается после первой главы;
- Соляные топи навсегда открываются роду на 3-м уровне после трёх подтверждённых вольных контрактов;
- каждые сутки сервер собирает по три предложения на открытую область из авторских модулей врага, цели, местности и осложнения;
- предложение хранится в базе и не может быть подменено клиентом на более лёгкую или выгодную комбинацию;
- принятый контракт сохраняется после окончания суточной ротации;
- позиционный бой использует ближнюю, среднюю, дальнюю и предельную дистанции;
- местность задаёт допустимую дистанцию и стоимость движения;
- доступны действия «Сблизиться» и «Отойти», а шанс побега зависит от реально созданного расстояния;
- ближние, дальние и маневренные противники по-разному меняют позицию;
- ремесленные приёмы зависят от дистанции: кузнецу нужно сблизиться, охотник сильнее издали, возчик подтягивает врага крюком;
- старые активные походы автоматически получают безопасные значения миграции и продолжаются по прежним правилам;
- один неподтверждённый запуск похода и один неподтверждённый боевой ход могут находиться в офлайн-очереди одновременно;
- серверные травмы влияют на расход сил, а сломанный инструмент блокирует ремесленный приём даже при прямом API-запросе;
- подтверждённые победы дают монеты, опыт, репутацию, трофеи и прогресс гильдии;
- мастерская содержит материалы, рецепты, ремонт, лечение, укрепление, перековку и временные эффекты;
- инструменты и оружие существуют как отдельные серийные экземпляры с качеством, прочностью, мастером, происхождением и историей владельцев;
- обычный рынок поддерживает частичные покупки, поиск, фильтры, сортировку и автоматическое истечение объявления;
- отдельный рынок уникальных экземпляров передаёт сам предмет без клонирования;
- ремесленные заказы резервируют награду заказчика и атомарно передают изделие и оплату;
- общие гильдии поддерживают приглашения, роли, казну, дерево, задания и закрытый чат;
- все экономические мутации используют `requestId`, поэтому повтор запроса не дублирует награду или расход;
- приватные API отвечают с `Cache-Control: no-store` и не попадают в Service Worker;
- схема 0.11 устанавливается миграцией `013_regions_and_positioning` с транзакционным откатом.

## Авторская процедурность

Контракт не генерируется из произвольных слов. Сервер выбирает совместимые заранее написанные модули:

- область;
- противника и его боевой стиль;
- цель работы;
- местность;
- осложнение;
- награду и трофей.

Одинаковая суточная ротация для конкретного аккаунта восстанавливается с теми же идентификаторами. Это сохраняет авторский тон и одновременно даёт повторяемый игровой цикл.

## Текущее техническое ограничение

Соляные топи уже являются полноценной областью свободных контрактов, но отдельная сюжетная глава с персонажами, решениями и региональной развязкой ещё не написана. Новые трофеи пока используются как торговые материалы; отдельные болотные рецепты, региональные события, естественное заживление травм и более сложные боевые эффекты местности остаются следующими этапами.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

PWA откроется на `http://localhost:5173`, API и сервер чатов работают на `http://localhost:3001`.

Команда `npm run dev` запускает сервер и Vite напрямую через Node.js и работает в Windows, Linux и GitHub Codespaces.

Раздельный запуск:

```bash
npm run dev:server
npm run dev:web
```

Данные сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. По умолчанию используется порт `3000`; `PORT` и `DATABASE_PATH` можно переопределить переменными окружения.

## Команды

```bash
npm run dev          # клиент и основной сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, типы и production-сборка
npm start            # production-сервер
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не только проценты к характеристикам.
2. Процедурность собирается из авторских модулей и не разрушает голос мира.
3. Мир не делится на очевидное добро и зло, но последствия решений понятны задним числом.
4. Рогалик наказывает за риск, сохраняя память рода, а не отменяя цену смерти.
5. Сервер является источником истины для боя, регионов, сюжета, героя и экономики.
6. Система считается завершённой только после проверки миграции, повторов запросов и сетевых сбоев.
