# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.3

Проект содержит законченную первую игровую главу и настоящий общий онлайн-слой:

- создание героя с именем и одним из шести ремёсел;
- пролог и три полноценных контракта с расследованиями и моральными развязками;
- ремесленные варианты решения событий, которые открывают новые пути, а не только меняют числа;
- детерминированный пошаговый бой с намерениями противника, защитой, подготовкой удара, лечением и отступлением;
- уникальное боевое действие для каждого ремесла;
- уровни, опыт, очки развития, здоровье, силы, чутьё, репутация, монеты и инвентарь;
- окончательная смерть персонажа и метапрогресс рода: слава, число погибших и наследуемые реликвии;
- необязательные серверные аккаунты: одиночная глава остаётся доступна без регистрации;
- общие гильдии в SQLite с лимитом 20 участников и вступлением только по приглашению;
- пользовательские роли, серверная проверка прав и защищённая иерархия исключения участников;
- общая казна с журналом каждой операции;
- еженедельные задания, уровни гильдии и пять веток дерева развития;
- поэтапное включение гильдейских бонусов через 4 и 8 часов после вступления;
- WebSocket-чаты `#Общий`, `#Торговля`, `#Гильдия` с переподключением и сохранением истории;
- сервер сам определяет имя и гильдию авторизованного игрока, поэтому закрытый канал нельзя получить подменой клиентских данных;
- адаптивная устанавливаемая PWA для телефона и компьютера;
- Service Worker не кэширует приватные API-ответы;
- автоматические тесты аккаунтов, API, гильдий, ролей, казны, чатов и игрового движка;
- единый запуск клиента и сервера в GitHub Codespaces.

## Текущее техническое ограничение

Основная одиночная игра пока хранит состояние персонажа в браузере. Сервер уже является источником истины для аккаунтов, состава гильдий, приглашений, ролей, дерева, казны и закрытого чата, но ещё не проверяет происхождение каждой личной монеты и боевой победы. Следующий этап — серверное состояние персонажа и очередь синхронизации офлайн-действий.

## Запуск в Codespaces

1. Открой репозиторий в GitHub Codespaces.
2. Дождись выполнения `npm install`.
3. Запусти:

```bash
npm run dev
```

Игра откроется на порту `5173`, API и сервер чатов работают на `3001`.

Данные аккаунтов и гильдий сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. Порт задаётся переменной `PORT`, путь к базе можно переопределить через `DATABASE_PATH`. По умолчанию используется порт `3000`.

Для серверной SQLite-модели требуется Node.js 24.15 или новее.

## Команды

```bash
npm run dev          # клиент и сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, проверка типов и production-сборка
npm start            # запуск production-сервера
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не просто даёт проценты к характеристикам.
2. Мир не делится на очевидное добро и зло, но последствия решений должны быть понятными задним числом.
3. Рогалик наказывает за риск, но метапрогресс сохраняет знания и память, не отменяя цену смерти.
4. Онлайн дополняет одиночный путь через чаты, гильдии, торговлю и общие события.
5. Каждая система проходит цикл: реализация, проверка, исправление и повторная проверка.
