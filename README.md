# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Что уже работает

- выбор одного из шести ремёсел;
- короткий интерактивный пролог с особыми решениями для разных ремёсел;
- здоровье, силы, чутьё, монеты, время и инвентарь;
- автоматическое локальное сохранение прохождения;
- адаптивный интерфейс для телефона и компьютера;
- PWA-манифест и Service Worker для установки и офлайн-запуска оболочки;
- WebSocket-чаты `#Общий`, `#Торговля`, `#Гильдия`;
- единый запуск клиента и сервера в GitHub Codespaces;
- CI-проверка TypeScript и production-сборки.

## Запуск в Codespaces

1. Открой репозиторий в GitHub Codespaces.
2. Дождись выполнения `npm install`.
3. Запусти:

```bash
npm run dev
```

Игра откроется на порту `5173`, сервер чатов работает на `3001`.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA и обслуживает WebSocket на одном порту. Порт задаётся переменной `PORT`, по умолчанию используется `3000`.

## Команды

```bash
npm run dev      # клиент и сервер
npm run check    # строгая проверка TypeScript
npm run build    # production-сборка
npm start        # запуск production-сервера
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не просто даёт проценты к характеристикам.
2. Мир не делится на очевидное добро и зло, но последствия решений должны быть понятными задним числом.
3. Рогалик наказывает за риск, но метапрогресс сохраняет знания, а не отменяет цену смерти.
4. Онлайн дополняет одиночный путь через чаты, гильдии, торговлю и общие события.
5. Каждая новая система проходит цикл: реализация, проверка, исправление, повторная проверка.
