# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.13

Проект содержит две серверные сюжетные главы, две области свободных походов, групповую боевую систему и единую экономику:

- один адаптивный PWA-интерфейс для компьютера и телефона;
- регистрация, HttpOnly-сессии, SQLite-база и серверный герой одного из шести ремёсел;
- первая глава в Верескове: 16 сцен, три расследования и моральная развязка;
- вторая глава в Соляных топях: 12 сцен, три расследования, два позиционных сюжетных боя и три взаимоисключающих финала;
- решения обеих глав защищены `requestId` и последовательными офлайн-очередями;
- окончательная смерть, поколения наследников, слава рода и наследуемые торговые активы;
- свободные области **Пепельный тракт** и **Соляные топи** с суточными авторскими контрактами;
- новые контракты Соляных топей создают отряд из ведущего противника и поддержки;
- игрок выбирает конкретную цель и видит её роль, здоровье, намерение, дистанцию и высоту;
- доступны ближняя, средняя, дальняя и предельная дистанции, а также три уровня высоты;
- отход и смена высоты могут вызвать удар зоны контроля;
- броня уменьшает физический урон, обереги защищают от порчи и контроля;
- экипировка разделена на независимые слоты **основная рука**, **броня** и **оберег**;
- старые выбранные инструменты автоматически переносятся в основную руку;
- раскладка трёх слотов сохраняется после рестарта и при создании наследника;
- мастерская содержит шесть новых ремесленных чертежей доспехов и оберегов;
- ремонтные комплекты, укрепление и перековка изменяют только предмет в основной руке;
- первый личный региональный босс — **Соляной воевода Глухобор**;
- Глухобор сражается вместе с загонщиком и утопленным певчим, занимает верхний ярус и переходит во вторую фазу на половине здоровья;
- во второй фазе появляется соляная тень, а босса нельзя победить одним ударом до срабатывания фазы;
- первая победа выдаёт связанный с родом мастерский **Белопанцирь Глухобора**;
- повторная победа доступна после семидневного восстановления колокольни;
- болотные материалы, рецепты, травмы, укрытия и ловушки остаются частью той же экономики;
- серийные предметы сохраняют качество, прочность, мастера, происхождение и историю владельцев;
- рынки, ремесленные заказы, гильдии и чаты используют того же героя и ту же SQLite-базу;
- приватные API отвечают с `Cache-Control: no-store` и не попадают в Service Worker;
- схема 0.13 устанавливается миграцией `016_equipment_slots_and_squad_combat`.

## Экипировка

У героя три независимых слота:

1. **Основная рука** — оружие или ремесленный инструмент. Изнашивается при атаке и ремесленном приёме.
2. **Броня** — уменьшает физический урон и теряет прочность при пробившем защиту ударе.
3. **Оберег** — даёт сопротивление порче, контролю, движению или работе с высотой.

Каждое ремесло получило собственный региональный чертёж. Носить изготовленный предмет может герой любого ремесла.

## Групповой бой

Групповой контракт не означает кооператив между игроками: один герой противостоит нескольким серверным противникам. Враги имеют разные роли:

- громила сближается и наносит тяжёлые удары;
- загонщик удерживает проход зоной контроля;
- дальний противник отходит и атакует с высоты;
- маневренный противник меняет дистанцию;
- босс меняет фазу и призывает подкрепление.

Игрок выбирает цель для атаки, ремесленного приёма и ловушки. Сервер хранит состояние каждого врага отдельно, поэтому повтор запроса не наносит урон второй раз.

## Вторая глава: Соляные топи

После открытия региона герой может расследовать три конфликта:

1. **Глухой колокол** — решить, кому принадлежит звон затопленной часовни и память об утонувших лодочниках.
2. **Белая лихорадка** — спасти рабочих варниц, выбрав между закрытием прибыльного чана и сокрытием костей под ним.
3. **Клятва тростника** — определить право на старую гать между солеварами и семьями охотников.

Финальный совет предлагает три необратимых решения: реформировать дом солеваров, освободить топи от исключительного права или уничтожить документы и заключить мир без общей правды.

## Авторская процедурность

Свободный контракт не генерируется из произвольных слов. Сервер соединяет совместимые заранее написанные модули области, противника, цели, местности, осложнения, награды и трофея. Одинаковая суточная ротация для конкретного аккаунта восстанавливается с теми же идентификаторами.

## Текущее техническое ограничение

Глухобор является личным региональным боссом, а не общесерверным событием. Другие игроки не участвуют в одном бою, гильдии пока не могут совместно открывать фазу босса, а коллективные решения ещё не изменяют общую карту. Следующие этапы: гильдейский босс, казна ресурсов, региональные события и серверные последствия решений.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

PWA откроется на `http://localhost:5173`, API и сервер чатов работают на `http://localhost:3001`.

Команда `npm run dev` запускает сервер и Vite напрямую через Node.js и работает в Windows, Linux и GitHub Codespaces.

Раздельный запуск:

```bash
npm run dev:server
npm run dev:web
```

Данные сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. По умолчанию используется порт `3000`; `PORT` и `DATABASE_PATH` можно переопределить переменными окружения.

## Команды

```bash
npm run dev          # клиент и основной сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, типы и production-сборка
npm start            # production-сервер
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не только проценты к характеристикам.
2. Процедурность собирается из авторских модулей и не разрушает голос мира.
3. Мир не делится на очевидное добро и зло, но последствия решений понятны задним числом.
4. Рогалик наказывает за риск, сохраняя память рода, а не отменяя цену смерти.
5. Сервер является источником истины для боя, регионов, сюжета, героя и экономики.
6. Система считается завершённой только после проверки миграции, повторов запросов и сетевых сбоев.
