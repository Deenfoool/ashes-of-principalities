# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.12

Проект содержит две серверные сюжетные главы, две области свободных походов и единую экономику:

- один адаптивный PWA-интерфейс для компьютера и телефона;
- регистрация, HttpOnly-сессии, SQLite-база и серверный герой одного из шести ремёсел;
- первая глава в Верескове: 16 сцен, три расследования и моральная развязка;
- вторая глава в Соляных топях: 12 сцен, три расследования, два позиционных сюжетных боя и три взаимоисключающих финала;
- решение второй главы записывается для текущего поколения и не может быть переиграно ради повторной награды;
- наследник сохраняет открытые регионы рода, но должен завершить первую главу прежде, чем начать сюжет топей;
- сюжетные решения обеих глав защищены `requestId` и последовательными офлайн-очередями;
- окончательная смерть, поколения наследников, слава рода и наследуемые торговые активы;
- две области свободных походов: **Пепельный тракт** и **Соляные топи**;
- Пепельный тракт открывается после первой главы;
- Соляные топи навсегда открываются роду на 3-м уровне после трёх побед на Пепельном тракте;
- каждые сутки сервер собирает по три контракта на открытую область из авторских модулей врага, цели, местности и осложнения;
- позиционный бой использует ближнюю, среднюю, дальнюю и предельную дистанции;
- доступны сближение, отход, укрытие и установка тростниковой ловушки;
- естественное укрытие зависит от местности, переносное требует тростникового экрана;
- ловушка расходуется сервером, может быть усилена рассольными шипами и не срабатывает повторно при повторе запроса;
- ремесленные приёмы зависят от дистанции и экипированного серийного предмета;
- новые болотные материалы: соляной мох, чёрный тростник, рассольный кристалл и утопленная бронза;
- существующие победы версии 0.11 получают недостающие региональные материалы один раз;
- добавлены соляные припарки, тростниковые петли и экраны, знаки тихой воды, болотные верёвки и рассольные шипы;
- новые травмы: соляной ожог, болотная лихорадка и глубокий порез;
- травмы естественно ослабевают только вне похода, а безопасный ночлег ускоряет восстановление;
- лихорадка повышает стоимость движения, глубокий порез повышает цену атак, соляной ожог усложняет полевые тактики;
- серверные травмы, ремонт и лечение остаются частью одной экономики;
- инструменты и оружие существуют как отдельные серийные экземпляры с качеством, прочностью, мастером и историей владельцев;
- мастерская, рынки, ремесленные заказы, гильдии и чаты используют того же героя и ту же базу;
- приватные API отвечают с `Cache-Control: no-store` и не попадают в Service Worker;
- миграции `014_salt_marsh_story_and_recovery` и `015_marsh_injury_penalties` выполняются транзакционно.

## Вторая глава: Соляные топи

После открытия региона герой может расследовать три конфликта:

1. **Глухой колокол** — решить, кому принадлежит звон затопленной часовни и память об утонувших лодочниках.
2. **Белая лихорадка** — спасти рабочих варниц, выбрав между закрытием прибыльного чана и сокрытием костей под ним.
3. **Клятва тростника** — определить право на старую гать между солеварами и семьями охотников.

Финальный совет предлагает три необратимых решения: реформировать дом солеваров, освободить топи от исключительного права или уничтожить документы и заключить мир без общей правды.

## Авторская процедурность

Свободный контракт не генерируется из произвольных слов. Сервер соединяет совместимые заранее написанные модули:

- область;
- противника и его боевой стиль;
- цель работы;
- местность;
- осложнение;
- награду и трофей.

Одинаковая суточная ротация для конкретного аккаунта восстанавливается с теми же идентификаторами. Это сохраняет авторский тон и одновременно даёт повторяемый игровой цикл.

## Текущее техническое ограничение

Вторая глава завершена как одиночный серверный сюжет, но в ней пока нет коллективных решений гильдии, регионального босса и долгосрочного изменения общесерверной карты. Укрытия и ловушки уже работают, однако высота, несколько противников, сложные состояния местности и броня остаются следующими этапами.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

PWA откроется на `http://localhost:5173`, API и сервер чатов работают на `http://localhost:3001`.

Команда `npm run dev` запускает сервер и Vite напрямую через Node.js и работает в Windows, Linux и GitHub Codespaces.

Раздельный запуск:

```bash
npm run dev:server
npm run dev:web
```

Данные сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. По умолчанию используется порт `3000`; `PORT` и `DATABASE_PATH` можно переопределить переменными окружения.

## Команды

```bash
npm run dev          # клиент и основной сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, типы и production-сборка
npm start            # production-сервер
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не только проценты к характеристикам.
2. Процедурность собирается из авторских модулей и не разрушает голос мира.
3. Мир не делится на очевидное добро и зло, но последствия решений понятны задним числом.
4. Рогалик наказывает за риск, сохраняя память рода, а не отменяя цену смерти.
5. Сервер является источником истины для боя, регионов, сюжета, героя и экономики.
6. Система считается завершённой только после проверки миграции, повторов запросов и сетевых сбоев.
