# Пепел Княжеств

Мрачная онлайн-игра в формате текстовой RPG-рогалика. Мир вдохновлён славянским фэнтези и суровой моральной неоднозначностью, но строится как самостоятельная вселенная.

## Вертикальный срез 0.5

Проект содержит законченную первую главу и единый серверный прогресс для авторизованного игрока:

- создание героя с именем и одним из шести ремёсел;
- серверный пролог и три сюжетных контракта с расследованиями и моральными развязками;
- 16 авторских сцен, ремесленные решения, доказательства, предметы и долгосрочные последствия;
- серверная проверка профессии, предметов, флагов, монет, сил и доступности контрактов;
- один герой, одна экономика и один инвентарь для сюжета, боёв, гильдии и вольных походов;
- пошаговый бой с намерениями противника, защитой, подготовкой, ремесленными приёмами и отступлением;
- сюжетные столкновения используют тот же серверный боевой движок, но не удваивают награды и прогресс контрактов;
- уровни, опыт, здоровье, силы, чутьё, репутация, монеты и серверный инвентарь;
- окончательная смерть, поколения наследников, слава рода и семейная реликвия;
- новый наследник получает новую первую главу, сохраняя родовую метапрогрессию;
- исход каждого контракта, история решений и завершение главы сохраняются в SQLite;
- одноразовые идентификаторы действий: повтор запроса не удваивает награду, решение, взнос или начало боя;
- отдельная офлайн-очередь сюжетных решений и действий героя с безопасным повтором после восстановления связи;
- вольные контракты и свободный отдых открываются только после завершения первой главы;
- гостевой локальный пролог остаётся демонстрационным режимом без общей экономики;
- после входа старые локальные разделы героя скрываются, остаются серверная игра, чаты, гильдия и аккаунт;
- общие гильдии с лимитом 20 участников и вступлением только по приглашению;
- пользовательские роли, серверная проверка прав, казна и полный журнал операций;
- взнос в казну сначала списывает реальные монеты серверного героя;
- гильдейские задания засчитываются только после подтверждённых сервером контрактов и побед;
- WebSocket-чаты `#Общий`, `#Торговля`, `#Гильдия` с переподключением и закрытым гильдейским каналом;
- адаптивная устанавливаемая PWA для телефона и компьютера;
- Service Worker не кэширует приватные API-ответы;
- автоматические тесты аккаунтов, API, персонажей, сюжетных сцен, боёв, наследования, миграции, идемпотентности, гильдий и чатов;
- единый запуск клиента и сервера в GitHub Codespaces.

## Текущее техническое ограничение

Гостевой режим по-прежнему использует старое локальное ядро как демонстрацию без регистрации. Для авторизованного игрока оно больше не является источником прогресса. Следующий этап — заменить оставшуюся оболочку единым маршрутизатором серверной игры, затем добавить травмы, качество и износ снаряжения, ремонт и ремесленное производство.

## Запуск в Codespaces

1. Открой репозиторий в GitHub Codespaces.
2. Дождись выполнения `npm install`.
3. Запусти:

```bash
npm run dev
```

Игра откроется на порту `5173`, API и сервер чатов работают на `3001`.

Данные аккаунтов, героев, сюжета и гильдий сохраняются в `data/game.db`, история чатов — в `data/chat.json`. Эти файлы не попадают в Git.

## Production

```bash
npm run build
npm start
```

После сборки Node-сервер отдаёт PWA, REST API и WebSocket на одном порту. Порт задаётся переменной `PORT`, путь к базе можно переопределить через `DATABASE_PATH`. По умолчанию используется порт `3000`.

Для серверной SQLite-модели требуется Node.js 24.15 или новее.

## Команды

```bash
npm run dev          # клиент и основной сервер разработки
npm test             # серверные тесты и дымовой тест игрового движка
npm run check        # строгая проверка TypeScript
npm run build        # тесты, проверка типов и production-сборка
npm start            # запуск production-сервера
```

## Принципы проекта

1. Ремесло открывает способы решения проблем, а не просто даёт проценты к характеристикам.
2. Мир не делится на очевидное добро и зло, но последствия решений должны быть понятными задним числом.
3. Рогалик наказывает за риск, но метапрогресс сохраняет знания и память, не отменяя цену смерти.
4. Онлайн дополняет личный путь через чаты, гильдии, торговлю и общие события.
5. Сервер является источником истины для сюжета, героя, общей экономики и наград.
6. Каждая система проходит цикл: реализация, проверка, исправление и повторная проверка.
